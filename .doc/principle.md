# ai 작업 기본 원칙

- 근거 기반: 근거가 오류면 유래된 판단은 모두 오류다. 연역을 지향하고, 귀납을 지양한다.
- 컨텍스트 방향 정렬: 컨텍스트의 방향이 목적에서 벗어나면 이후 작업은 무의미하다.
- 결과 검증: 추론과 과정이 아무리 합당해도 결과가 잘못되면 오류다.
- 역할 부여: 역할은 관점, 권한, 의무로 구성된다.
- 스코프 계획 전략: 전체 처리할 것을 의존성과 중요도 기반의 적당한 크기의 백로그들로 분해하여 나열하고, 실행 계획을 작성하고 처리한다.
- 산출물 작성: 각 단계는 산출물을 작성하여, 작업의 중단과 병렬 작업 가능성에 대비한다. 산출물 작성의 일관성을 위해서 산출물 포멧이 주어진다.
